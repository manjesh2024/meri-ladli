# Diwali gift image assets

Add the final, individually refined product images to this folder using these exact filenames:

- `galaxy-smooth-milk.webp`
- `kitkat.webp`
- `cadbury-crispello.webp`
- `bournville-50-dark.webp`
- `pearl-wish-gift-set.webp`
- `pearl-necklace.webp`
- `bracelet.webp`
- `gift-wrapping.webp`

Use one product per image (no collage), preferably square or portrait, with the product clearly visible. Keep the original packaging/design faithful. The gift reveal already references these paths and displays a graceful icon fallback until the images are added.
